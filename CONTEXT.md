# CV Website

A personal CV/resume website, generated by a static site generator and deployed to GitHub Pages via a GitHub Actions pipeline. Built by Tom as a learning project — the emphasis is on Tom hand-implementing the build himself, not on having it built for him.

## Language

**Site**:
The public CV website — the static pages generated from CV data and deployed to GitHub Pages.
_Avoid_: portfolio, resume page, app

**CV data**:
The structured content (experience, education, skills, etc.) the Site is generated from, sourced from Tom's existing resume material.
_Avoid_: content, resume text, copy

**Pipeline**:
The GitHub Actions workflow that builds the Site from CV data and deploys it to GitHub Pages on push.
_Avoid_: CI, deploy script, build process

**Build spec**:
The output of this wayfinder effort: the locked decisions on SSG choice, Site structure, and Pipeline design, detailed enough for Tom to hand-implement without further design decisions.
_Avoid_: plan, design doc
